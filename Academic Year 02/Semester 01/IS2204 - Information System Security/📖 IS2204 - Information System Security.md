#Lesson-Plan 

This lesslon provides a comprehensive foundation for protecting computer-related assets, focusing on the methods and technologies required to ensure the security of data and the systems that manage it. The module transitions from core definitions and theoretical frameworks, such as the **CIA Triad (Confidentiality, Integrity, and Availability)**, into practical applications like cryptography, secure payment systems, and defense against malicious code.

---

Below is a summary of the key topics covered in this lesson, organized by their focus areas:

1. [[Introduction to Information System Security]]

This section defines what it means for a system to be "secure." It covers:

- **The Valuables:** Moving from physical assets (like money in a bank) to information, which is the currency of the 21st century.
- **Security Goals:** Understanding the requirements for a secure system: **Confidentiality** (authorized access only), **Integrity** (data is precise and unmodified), and **Availability** (timely response and reliability).
- **Terminology:** Distinguishing between **Vulnerabilities** (weaknesses), **Threats** (harmful circumstances), **Attacks** (human exploitation), and **Controls** (protective measures).

2. [[Foundations of Cryptography]]

This area explores the art and science of secret writing to protect sensitive information.

- **Symmetric Key Cryptography:** Using a single shared secret key for both encryption and decryption. It is fast and ideal for bulk data but faces challenges with key distribution.
- **Asymmetric Key Cryptography (Public-Key):** Using a pair of keys (public and private). This topic covers algorithms like **RSA** and the principles of digital signatures for authentication and non-repudiation.
- **Hashing:** The objective of disguising information to ensure its integrity and authenticity.

3. [[Application and Document Security]]

These lessons focus on securing specific types of data and communication methods:

- **Email Security:** Utilizing protocols like **PGP** and **S/MIME**.
- **Document Security:** Managing the document lifecycle (creation, storage, sharing, and destruction) and protecting against physical and digital threats using **Access Control Mechanisms** (like Role-Based Access Control) and **Data Loss Prevention (DLP)**.

4. [[Network and Web Security Protocols]]

This section deals with the security of data in motion across the internet:

- **Transport Layer Security (TLS/SSL):** The protocol layer that provides privacy and integrity for applications like web browsing (HTTPS).
- **Network Security Protocols:** Securing traffic below the application layer using **DNSSEC** (securing name resolution), **SSH** (secure remote login), and **IPSec** (transparent protection at the network layer).

5. [[Financial Systems and Blockchain]]

A deep dive into how security is applied to electronic money and distributed ledgers:

- **Credit Card Payments:** The architecture of internet transactions and the perspectives of banks versus customers regarding risk and security.
- **Bitcoin and Blockchain:** The creation of decentralized currency through mining and the security analysis of distributed ledgers.

6. [[Malicious Code and Defenses]]

The final area covers the threats that compromise systems and the tools used to stop them:

- **Malware Classification:** Categorizing malicious software by how it spreads (**Propagation Mechanism** like viruses and worms) and what it does (**Payload** like ransomware, spyware, or rootkits).
- **Defensive Technologies:** The use of **Firewalls** to filter perimeter traffic and **Intrusion Detection Systems (IDS)** or **Intrusion Prevention Systems (IPS)** to monitor and respond to malicious behavior inside the network.
